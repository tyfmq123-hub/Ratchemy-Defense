JH UnitInfo 씬 — 작업 정리

작업일: 2026-06-08  |  담당: Member_Yoon

1. 구조 결정 사항

  • 씬에 두 ScrollRect — 아군 / 적군 분리 구성
  • 표시 전용 스크립트 방식 채택 (소환·코스트 로직 없음)
  • 적군 데이터: 기존 EnemyUnitData 재활용 (표시 필드 추가)
  • 아군 데이터: 신규 PlayerUnitDisplayData 생성, 스탯은 프리팹에서 참조
  • 공통 인터페이스 IUnitDisplayData 로 카드·팝업 재사용
  • 아군 number = cost (동일 필드 공유)

2. 카드 / 팝업 표시 항목

소형 카드 (ScrollRect)

  • 번호 (아군만 표시, 0이면 숨김)
  • 유닛 이름
  • 유닛 이미지 (원본 비율 유지)
  • 엘리먼트 타입
  • 설명

상세 팝업 (클릭 시)

  • 제목: 유닛이름 상세 정보
  • 유닛 이미지
  • 코스트 (아군만, 0이면 숨김) — N 코스트 형식
  • 롤 타입 (근접 / 원거리)
  • 엘리먼트 타입 (원소)
  • 스탯: 공격력, HP, 이동속도, 공격속도, 사거리
  • 설명

3. 생성 · 수정 파일

수정EnemyUnitData.cs
표시 정보 필드 추가 (unitName, unitSprite, unitSpriteColor, unitSpriteSize, roleType, elementType, description) / IUnitDisplayData 구현
신규IUnitDisplayData.cs
아군·적군 공통 인터페이스 — Number, Cost, UnitName, UnitSprite, RoleType, ElementType, Description, Damage, MaxHp, MoveSpeed, AttackSpeed, AttackRange
신규UnitInfoCard.cs
소형 카드 표시 스크립트 / IPointerClickHandler로 클릭 시 팝업 호출
신규UnitInfoPopup.cs
상세 정보 팝업 / Show(IUnitDisplayData), Hide() / CheckButton으로 닫기
신규EnemyInfoCardSpawner.cs
적군 카드 동적 생성 / EnemyUnitData 배열 순회 / AllyCountText 자동 업데이트
신규PlayerUnitDisplayData.cs
아군 표시 전용 ScriptableObject / 스탯은 unitPrefab(PlayerUnitBase)에서 참조 / number = cost
신규PlayerInfoCardSpawner.cs
아군 카드 동적 생성 / PlayerUnitDisplayData 배열 순회 / AllyCountText 자동 업데이트

4. 남은 작업

Unity 에디터 작업
  • UnitCard 프리팹에 UnitInfoCard.cs 연결 및 5개 필드 참조 설정
  • EnemyInfoPopup에 UnitInfoPopup.cs 연결 및 필드 참조 설정
  • 적군 Content에 EnemyInfoCardSpawner 연결
  • 아군 Content에 PlayerInfoCardSpawner 연결
데이터 입력
  • PlayerUnitDisplayData 에셋 5개 생성 후 데이터 입력
    Create → Game → Player Unit Display Data
  • 각 EnemyUnitData 에셋에 roleType / elementType 입력 확인
스킬 정보 구현 미완
  • SkillDisplayData.cs ScriptableObject 생성 (skillName, skillDescription)
  • IUnitDisplayData에 SkillDisplayData[] Skills 추가
  • EnemyUnitData / PlayerUnitDisplayData에 skills 배열 추가
  • 팝업 UI에 SkillContent 컨테이너 추가 (VerticalLayoutGroup)
  • 스킬 항목 프리팹 제작 (이름 TMP + 설명 TMP)
  • UnitInfoPopup에서 스킬 동적 생성 / 없으면 섹션 숨김
