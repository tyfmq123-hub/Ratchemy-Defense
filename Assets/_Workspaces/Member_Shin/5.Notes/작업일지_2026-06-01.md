## 유니티 작업 내용

### 1. 유닛 스폰 시스템 (`UnitsSpawnPoint.cs`)
- 플레이어 유닛을 지정된 스폰 포인트에 일괄 소환하는 `SpawnAllPlayers()` 구현
- 적 유닛을 랜덤 스폰 포인트에 일정 간격으로 계속 소환하는 `SpawnRandomEnemy()` 구현
- `InvokeRepeating`으로 게임 시작 1초 후부터 `enemySpawnInterval`(기본 2초) 간격으로 적 자동 소환
- 프리팹 및 스폰 포인트 미설정 시 경고 로그 출력 처리

### 2. 배틀 카메라 컨트롤러 (`BattleCameraController.cs`)
- 마우스 드래그로 카메라를 좌우로 이동하는 기능 구현
- 배경 스프라이트 크기에 맞춰 카메라 이동 범위를 자동 계산 (`CalculateCameraLimit()`)
- 카메라 Y, Z 고정 / 직교 카메라(Orthographic) 설정
- Input System(`Mouse.current`) 기반으로 드래그 처리

### 3. 베이스 체력(온도) UI (`BaseHealthUI.cs`)
- 베이스의 현재 온도를 UI 이미지 fillAmount로 시각화
- 온도 비율에 따라 색상이 변하는 그라데이션 구현
  - 0~50% → 파랑(정상) → 노랑(경고)
  - 50~100% → 노랑(경고) → 빨강(위험)
- TextMeshPro로 현재 온도를 `°C` 단위로 표시
- Inspector에서 `previewTemperature` 슬라이더로 실시간 미리보기 가능

### 4. 배틀 씬 리소스 추가
- `BattleBackground.png` 배틀 씬 배경 이미지
- `BaseHealthBG.png` 베이스 체력 UI 배경 이미지
- `BaseHealthFill.png` 베이스 체력 UI 채움 이미지
- `SSH.unity` 테스트 씬 작업

## 이후 추가 작업 (오후)

### 5. 적 스포너 리팩토링 (`EnemySpawner.cs`)
- `WaveSetting`(웨이브별 적 목록, 마릿수, 생성 간격)을 받아 코루틴으로 적을 순차 생성
- 중복 스폰 방지: 이전 코루틴 실행 중이면 자동 중단 후 재시작
- 모든 적 생성 완료 시 `onWaveSpawnFinished` 콜백으로 WaveManager에 알림
- 스크립트 폴더 정리: `Scripts/Spawners/` 하위로 이동

### 6. 웨이브 매니저 (`WaveManager.cs`)
- `WaveSetting[]` 배열로 웨이브별 적 구성 관리
- 웨이브 시작 → 적 생성 완료 → 즉시 다음 웨이브 시작 흐름 구현
- 카운트다운 기간 동안 `EnvironmentGaugeUI`에 남은 시간 전달
- `WaveUI`에 현재 웨이브 번호(`WAVE.1`, `WAVE.2` ...) 표시
- 모든 웨이브 완료 시 `CLEAR`, `FINAL` 문구 표시

### 7. 베이스 체력 시스템 (`BaseHealth.cs`)
- 배터리 온도 개념으로 베이스 체력 관리
- 적이 기지 도달 시 `OnTriggerEnter2D`로 감지 → `EnemyBaseDamage`에서 온도 수치 수령
- 폭주 온도(`thermalRunawayTemperature`) 도달 시 게임 오버 처리 예정
- `BaseHealthUI`와 연동하여 실시간 온도 UI 반영

### 8. 적 피해 스크립트 (`EnemyBaseDamage.cs`)
- 적 유닛이 기지에 닿으면 온도 피해를 주는 스크립트
- `hasReachedBase` 플래그로 중복 피해 방지
- 기지 도달 즉시 적 오브젝트 삭제 처리

### 9. 환경 게이지 UI (`EnvironmentGaugeUI.cs`)
- 시계 이미지(10단계 스프라이트)로 남은 시간을 시각적으로 표현
- 남은 시간에 따라 `gaugeSprites[]` 배열에서 적절한 이미지 자동 선택
- 웨이브 시작 시 `GO!`, 전체 완료 시 `CLEAR` 문구 표시

### 10. 웨이브 UI (`WaveUI.cs`)
- 현재 웨이브를 `WAVE.1`, `WAVE.2` 형식으로 화면 표시
