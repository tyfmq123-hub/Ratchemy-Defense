1. 프로젝트 개요

프로젝트명

Ratchemy Defense (래트케미 디펜스)

목표

유니티 중간 프로젝트용 플레이 가능한 프로토타입 — 스테이지 선택부터 배틀, 승패까지 완결된 루프

팀 구성

3인 팀 · 팀장 전쇼릅 (Merge / _Project 반영 담당)

플레이 타깃

약 3~4분 웨이브 서바이벌 후 보스전 · 카드 소환형 전략 디펜스

2. 세계관 & 컨셉

플레이어는 고출력 배터리 공장의 안전을 책임지는 쥐(SCP) 요원들을 지휘한다. 산업용 배터리에서 누출된 화염·번개 에너지가 슬라임과 도마뱀 형태의 적으로 변이되어 시설을 향해 몰려온다.

적이 기지(배터리)에 도달하면 온도가 상승하고, 130°C 열폭주에 도달하면 패배한다. 모든 웨이브를 버티고 최종 보스 「열폭주 슬라임」을 처치하면 승리한다.

아군 테마

안전 관리 쥐 부대

절연, 냉각, 탱킹, 안전관리, 선봉대장 등 산업 안전·에너지 관리 역할을 쥐 유닛으로 의인화

적 테마

화염 슬라임 (Flame)

배터리 방출 에너지를 흡수한 슬라임. 오라·투사체·자폭으로 온도 상승 압박

적 테마

번개 도마뱀 (Thunder)

전류를 몸에 둔 도마뱀형 적. 원거리 번개·체인 라이트닝으로 아군 라인 교란

3. 핵심 게임 루프

  1. 스테이지 선택 → 스토리 만화 컷신 확인
  2. 유닛 정보(Unit Info)에서 아군·적군 스펙 확인
  3. 배틀 진입 — 코스트를 모아 카드로 유닛 소환
  4. 4웨이브 적 러시 방어 → 보스 스테이지
  5. 보스 처치(승리) 또는 배터리 130°C(패배) → 결과 UI

4. 씬 플로우

0.App (AppManager, BGM) └→ 1.StartScene — 타이틀 · START / EXIT └→ 2.StageScene — 스테이지 선택 (13개 UI, 현재 단일 경로 가능) └→ 3.StoryScene — 만화 컷신 (15초 자동넘김 + Timer 애니) └→ 4.UnitInfoScene — 아군 5종 · 적 6종+보스 정보 └→ 5.BattleScene — 웨이브 디펜스 + 보스전 ├→ 승리: 만화 4컷 → VictoryResultUI └→ 패배: 만화 4컷 → DefeatResultUI

씬 전환은 AppManager의 Additive 로딩으로 통일. 이전 씬 언로드 후 새 씬 활성화.

5. 승리 / 패배 조건

결과조건후속 처리
승리 보스 BossBase.OnBossDead → GameManager.Victory() 승리 만화 4컷 → VictoryResultUI (MA 등급 / SA% 표시)
패배 배터리 온도 130°C 열폭주 (BaseHealth) 패배 만화 4컷 → DefeatResultUI

승리 등급 (배터리 잔여 온도 기준)

온도SA%등급
< 20°C100%Perfect
< 40°C80%Normal
< 60°C60%중간
< 80°C40%나쁨
< 100°C20%위험
≥ 100°C0%실패

6. 배틀 시스템

코스트 시스템

항목값
시작 코스트0
최대 코스트20
회복 속도1초당 +1 (배틀 시작 후 활성화)
유닛 사망 환급소환 코스트의 50% (deathRefundRatio)
소환 위치A / B 스폰 포인트 교대

기지(배터리) 온도

  • 적이 기지에 도달하면 온도 상승 + 안전관리 점수 감소
  • UI: BaseHealthUI — 온도 게이지 색상 변화
  • 열폭주 임계값: 130°C

웨이브 매니저

  • 총 4웨이브 + 보스 스테이지
  • 웨이브별 제한 시간 · 스폰 수 · 스폰 간격 · 적 구성 개별 설정
  • 순차 스폰(spawnInOrder)으로 정확한 적 조합 지정 가능
  • 4웨이브 클리어 시 보스 경고 UI → 보스전
  • 보스 HP: 웨이브 클리어마다 최대 체력 20% 감소
